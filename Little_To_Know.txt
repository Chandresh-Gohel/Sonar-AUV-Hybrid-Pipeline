1. PROJECT OVERVIEW
================================================================

Phase I — Preprocessing Study
  Compares raw sonar input vs a hybrid MOG2+TVG 3-channel tensor
  across 8 YOLO variants (YOLOv5/v8/v11/v26, nano & small) on
  the CFC Tiny dataset split. Published at IEEE I3CTCON 2026.

Phase II — Domain-Adaptive Object Detection (DAOD)
  Self-training pipeline transferring a source-trained detector
  to the unlabelled Kenai Channel target site.
  Steps: pseudo-label generation → Kalman-centroid temporal
  filtering → 50/50 mixed fine-tuning. Zero target annotations.

Key finding:
  Compact detectors (nano) benefit from MOG2+TVG preprocessing.
  High-capacity detectors (small) are degraded by it — use raw.
  This rule holds through both Phase I and Phase II.

2. INSTALLATION & SETUP
================================================================

--- Install dependencies ---
  pip install -r requirements.txt

--- Set your data path (DOAD_WORK scripts) ---
  All DOAD scripts read one environment variable:

  Linux / macOS:
    export SONAR_BASE_DIR=/path/to/_SONAR_RUN_3

  Windows (cmd):
    set SONAR_BASE_DIR=D:\_SONAR_RUN_3

  Windows (PowerShell):
    $env:SONAR_BASE_DIR = "D:\_SONAR_RUN_3"

  Alternatively, open DOAD_WORK/config.py and edit BASE_DIR
  directly. Every DOAD script imports from config.py — one
  edit propagates everywhere.

--- SAME_SITE_WORK paths (Phase I preprocessing) ---
  export SONAR_INPUT_DIR=/path/to/raw
  export SONAR_OUTPUT_DIR=/path/to/data_preprocessed/raw
  export SONAR_IMAGE_BASE_DIR=/path/to/data_preprocessed/raw

  (Defaults: ./data/raw and ./data_preprocessed/raw)

--- Inference video path ---
  export SONAR_VIDEO_PATH=/path/to/your_video.mp4

4. PHASE I — QUICK START  (SAME_SITE_WORK/)
================================================================

Step 1 — Prepare MOT annotations -> CSV
  python create_csv.py \
    --annotations_dir annotations-tiny \
    --images_dir raw \
    --output_train_csv train_annotations.csv \
    --output_test_csv test_annotations.csv

Step 2 — Preprocess raw sonar sequences
  # Set env var first (or edit pre_pro_data.py directly)
  export SONAR_INPUT_DIR=/path/to/raw
  export SONAR_OUTPUT_DIR=/path/to/preprocessed/raw
  python pre_pro_data.py

Step 3 — Build YOLO dataset
  export SONAR_IMAGE_BASE_DIR=/path/to/preprocessed/raw
  python convert_csv_to_YOLO.py

Step 4 — Update YAML paths
  Edit sonar_dataset.yaml and sonar_dataset_pre_pro.yaml:
    path: /absolute/path/to/your/sonar_yolo_dataset

Step 5 — Train
  python train_yolo_raw.py        # raw pipeline (8 models)
  python train_yolo_pre_pro.py    # preprocessed pipeline (8 models)

Step 6 — Evaluate
  python evaluate_yolo_raw.py
  python evaluate_yolo_pre_pro.py

================================================================
5. PHASE II — QUICK START  (DOAD_WORK/)
================================================================

  export SONAR_BASE_DIR=/path/to/_SONAR_RUN_3
  cd DOAD_WORK

--- Prepare source data ---
  python convert_cfc_labels.py --split train
  python convert_cfc_labels.py --split val

  python preprocess_cfc.py --mode mog2tvg --split train
  python preprocess_cfc.py --mode mog2tvg --split val
  python preprocess_cfc.py --mode raw     --split train
  python preprocess_cfc.py --mode raw     --split val

  python build_yolo_dataset.py --mode mog2tvg
  python build_yolo_dataset.py --mode raw

--- Train source burn-in models ---
  python train_cfc.py --mode yolov5n_mog
  python train_cfc.py --mode yolov8s_raw
  python train_cfc.py --mode yolov26s_mog
  python train_cfc.py --mode yolov26s_raw

--- DAOD pipeline (repeat for each mode) ---
  python pseudo_label.py   --mode yolov5n_mog
  python temporal_filter.py --mode yolov5n_mog
  python dataset_mixer.py  --mode yolov5n_mog
  python finetune.py       --mode yolov5n_mog

--- Evaluate ---
  python evaluate_daod_full.py --mode all

--- Inference ---
  export SONAR_VIDEO_PATH=/path/to/video.mp4
  python inference.py --model yolov26s_raw --mode daod

7. KEY RESULTS
================================================================

Phase I — CFC Tiny val (3,794 frames):
  Detector     Pipeline      MAE     mAP@0.5
  ---------    ----------    -----   -------
  YOLOv5n      MOG2+TVG      0.729   0.772
  YOLOv8s      Raw           0.688   0.798
  YOLOv26s     Raw           0.575   0.836   <- Best overall
  YOLOv26s     MOG2+TVG      0.613   0.850

Phase II — Channel test (13,090 frames, 41,761 GT fish):
  Config              Mode         MAE     mAP@0.5   FPS
  ----------------    ---------    -----   -------   ----
  YOLOv5n+MOG/TVG     source       2.3465  0.4168    45.4
  YOLOv5n+MOG/TVG     DAOD ↑       2.1620  0.4424    48.9
  YOLOv8s+raw         source       2.2963  0.3491    48.8
  YOLOv8s+raw         DAOD ↑       2.0348  0.3796    48.0
  YOLOv26s+raw        source       2.0411  0.4012    72.6  <- Best
  YOLOv26s+MOG/TVG    DAOD ↑       2.4706  0.4535    76.2

Jetson Orin edge deployment:
  YOLOv26s+raw DAOD:  53.37 FPS
  YOLOv26s+MOG DAOD:  23.50 FPS

CPU benchmark (Intel i7-9700, 100 runs):
  YOLOv5n+MOG/TVG:    30.95 FPS
  YOLOv8s+raw:        25.68 FPS
  YOLOv26s+raw:       26.88 FPS
